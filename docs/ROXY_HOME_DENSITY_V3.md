# ROXY home density v3

The Home route is a product dashboard, not a marketing landing page.

## First-screen hierarchy

1. compact product header with authoritative balance;
2. compact hero with the primary **Создать** action inside the hero;
3. 8 quick product tools;
4. model directions;
5. compact promotional carousel;
6. active/recent generations.

The promotional carousel is secondary content and must never displace creation/tools/models from the first useful viewport.

## Size contract

- mobile hero: about 78px;
- mobile promo cards: max 92px;
- desktop promo cards: max 108px;
- four quick tools per row on mobile;
- no duplicate balance card on Home;
- promo copy is line-clamped rather than expanding the card;
- desktop/FHD uses width for more cards/columns rather than larger cards.

All product actions reuse existing Mini App routes/clients; this layer adds no new backend calls.
