# Approved ROXY reference matrix

| How ROX is received | Amount | Withdrawable |
| --- | ---: | :---: |
| 🎁 Welcome bonus | 50 ROX | No |
| 👤 Invited friend | 30 ROX | No |
| 🔁 Prompt repeat | 5 ROX | No |
| 👥 Referral level 1 | 30% of real top-ups | Yes |
| 👥 Referral level 2 | 5% of real top-ups | Yes |
| 💰 Minimum withdrawal | 3,000 ROX | Yes |

The product uses two accounting balances:

- `bonus_rox`: internal spend balance; it is never a withdrawal source;
- `withdrawable_rox`: partner earnings backed by real successful top-ups.

Public conversion is fixed at **1 ROX = 1 ₽**.
