## Rules of evidence

A candidate is promoted to **confirmed** only when at least one of these exists:

1. a deterministic code path showing the incorrect state transition or contract mismatch;
2. a failing regression test that reproduces the behavior;
3. a production/user reproduction that maps to the same code path.

A fix is **done** only after the regression is green on the PR head, protected checks are green on the current base, the PR is merged, and the exact production SHA is verified when the change affects production runtime/UI.

## Confirmed findings

### BH-001 — Home and Catalog are split into two primary screens

**Status:** fixing on `fix/home-is-catalog-20260902`

**Product contract:** Home **is** Catalog. Models belong to **Create**; the Catalog is the discovery surface for ROXY capabilities, current trends, templates/categories and account/service entry points.

**Reproduction / code evidence:**

- live `RoxySocialApp` accepts both `home` and `catalog` as independent routes;
- BottomNav exposes both `Студия` (`home`) and `Каталог` (`catalog`);
- `home` renders `HomeScreen`, while `catalog` renders a separate `CatalogScreen`;
- trend Back flow persists `route=catalog`, creating a second root destination;
- feature discovery (`CatalogFeatureHub`, `CatalogParityFeatures`) is attached only to the Catalog selector, so capabilities are not consistently visible on the actual root screen.

**User impact:** duplicate primary navigation, inconsistent Back/deep-link destination, duplicated trend discovery surfaces, and ROXY capabilities appearing on a different screen from the actual Home root.

**Fix contract:**

- `home` remains the only root state so native Telegram Back semantics stay correct;
- visible Home tab becomes `Каталог`;
- legacy `route=catalog` is normalized to `route=home`;
- the old Catalog tab is removed from visible navigation;
- Catalog feature/service enhancers mount on Home;
- current trends → categories/templates → capability/service surfaces are kept on the canonical Home Catalog;
- legacy duplicate Home sections are hidden rather than becoming a second discovery source;
- Playwright covers direct Home, legacy `route=catalog`, and trend native-Back return.
